Qo'llanma: yangi model qo'shish (qayerdan olinadi, qanday sozlanadi)
  1. Faylni toping. huggingface.co → qidiruvga model nomi GGUF → modelning Files bo'limi → …q4_k_m.gguf (telefon uchun eng yaxshi muvozanat) → yuklab olish (↓) tugmasining havolasi: https://huggingface.co/…/resolve/main/…gguf. Faqat https havola qabul qilinadi.
  2. "+ Yangi model" → havolani qo'ying → "HuggingFace'dan sha256/hajmni olish" bosing (hajm va tekshiruv kodi avtomatik; ilova yuklangan faylni shu bilan tekshiradi). Keyin "RAM ni taxmin qilish".
  3. Daraja avtomatik: parametr soni ≤ 1B → Tezkor (faqat Chat, bitta vazifa, Rol va System prompt kerak); 1.5–2B → Agent (ixcham); 3B+ → Kuchli (RAM ogohlantirishi bilan). DeepSeek-R1 oilasi doim Chat.
  4. System prompt — modelga nima qilishini aytadi. Namunalardan birini tanlab o'zgartiring. Qoidalar: faqat inglizcha; bitta vazifa; 1–2 qisqa qoida (≤1B uchun ~60–80 token); "javob birinchi, kirish so'zlarsiz"; bilmasa "I'm not sure."; oxirida "buyruq bajara olmaysan". Bo'sh qoldirsangiz — ilovadagi standart (Rol bo'yicha) prompt ishlaydi. Eslatma: bu prompt faqat Chat rejimidagi modellarda ishlatiladi; Agent/Kuchli modellar ilovaning agent promptini oladi — ularga qo'shimcha ko'rsatma berish uchun Agent ko'rsatmasi maydonidan foydalaning.
  5. Agent ko'rsatmasi — ilovaning standart agent promptini almashtirmaydi, uning oxiriga qo'shiladi (asbob formati va xavfsizlik qoidalari o'zgarmaydi). Faqat Agent (1.5–2B) va Kuchli (3B+) modellarda ishlaydi; Chat (≤1B) modellarda ishlatilmaydi. Qisqa va inglizcha yozing. Ixcham Agent (1.5–2B) modellarda faqat dastlabki 400 belgi yuboriladi, Kuchli (3B+) modellarda 1000 belgigacha. Maqsad: javob uslubi, til yoki soha qoidasi (masalan, "Keep answers short. Prefer Python for scripts."). Qo'shimcha matn har bir suhbat boshida modelga yuboriladi, shuning uchun uzun yozmang.
  6. Faol = true qilib saqlang — ilova katalogni ~5 daqiqada yangilaydi. Tartibni ↑ ↓ bilan o'zgartiring (Tezkor tepada, 3B+ pastda). Ro'yxat o'zgarishidan oldin Zaxira (pastda) orqali nusxa oling.

Foydalanuvchilar ilovadagi Sozlamalar → Fikr bildirish orqali yuborgan fikrlar. Faqat ularning o'zi yozgan matn, turi, ixtiyoriy aloqa, ilova versiyasi va tili saqlanadi (chat matni emas; faqat «AI shikoyati» turida foydalanuvchi shikoyat qilgan bitta AI javobi ham bor). Foydalanuvchi hisobini o'chirsa, fikrlari ham o'chadi. Bir foydalanuvchi soatiga 5 ta, kuniga 15 tagacha yubora oladi.

Bu yerda yozilgan e'lon foydalanuvchilar telefoniga faqat bildirishnoma (push) sifatida boradi (bosh sahifada banner ko'rsatilmaydi). Til tanlansa — faqat shu tildagilarga. Bildirishnoma ilova yopiq bo'lsa ham keladi, lekin foydalanuvchi yangi versiyani bir marta ochgan va bildirishnomaga ruxsat bergan bo'lishi kerak.

Ilovaning yangi versiyasi chiqqanda foydalanuvchilarga bosh sahifada yopsa bo'ladigan eslatma ko'rsatadi (bosilsa Google Play ochiladi). Faqat eskiroq versiyadagilarga chiqadi. Majburiy emas — foydalanuvchi yopsa, shu versiya uchun qayta chiqmaydi. Ilova eslatmani bosh sahifa ochilganda yangilaydi (~1 daqiqa kesh).

Admin paneldagi o'zgarishlar: kim, qachon, nima. Modellarda har bir o'zgarishni Bekor qilish tugmasi bilan oldingi holatiga qaytarish mumkin. Faqat tartibni (↑ ↓) o'zgartirish yozilmaydi. Yozuvlar 180 kun saqlanadi.
